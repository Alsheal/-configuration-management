**Задание 1**
grep -o '^[^:]*' /etc/passwd | sort
-о - выводить только совпашую часть строки
'^[^:]*' - регулярное выражение:
^ - начало строки
[^:]* - последовательность любых символов, кроме двоеточия
| sort - строки отсортированы в алфавитном порядке
